# 版本与发布策略

自首个公开版本起，GitHub Releases 将作为 Elevo AI Gateway 正式版本说明的公开归档。此仓库不会根据内部构建号补造历史版本。

## 版本号

公开版本采用 `MAJOR.MINOR.PATCH`：

- `MAJOR`：包含需要明确迁移的重大不兼容变化。
- `MINOR`：向后兼容的新能力或重要体验改进。
- `PATCH`：向后兼容的问题修复、安全加固和小幅优化。

预览版本可使用 `-preview.N` 后缀。部署环境显示的内部构建号可能比公开版本更细，不改变公开兼容性承诺。

## 每个版本包含什么

每份正式 Release 至少说明：

- 版本状态和发布日期；
- 面向用户的新增、改进与修复；
- API、配置、权限、计费或数据行为变化；
- 是否需要管理员或调用方执行操作；
- 已知限制、弃用项和关联 Issue；
- 必要时提供升级与回滚注意事项。

只影响内部实现、且不改变用户行为的提交不会逐条公开。

## 兼容性原则

- 已发布稳定 API 的兼容变更进入 `MINOR` 或 `PATCH`。
- 不兼容 API、认证、计费或配置变化必须在发布说明中突出标记，并提供迁移路径。
- 安全或合规风险要求紧急变更时，可能缩短通知期；Release 会解释影响和用户操作。
- 预览能力不承诺稳定接口，但仍会尽量提供变更说明。

## 弃用流程

弃用项会依次经历“宣布弃用、提供替代方案、保留迁移窗口、正式移除”。实际时间以对应 Release 为准，不以路线图中的顺序推断发布日期。

## 获取更新

在 GitHub 仓库右上角选择 **Watch > Custom > Releases**，即可只订阅正式发布通知。产品运行状态与版本发布相互独立，请通过[服务状态页](https://gateway.elevo.vip/portal/public/status)查看实时情况。
