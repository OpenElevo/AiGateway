# 特性与能力

本文描述 Elevo AI Gateway 面向用户的能力边界。具体可用模型、端点、额度和策略由租户配置决定，应以控制台和在线文档为准。

## 统一模型接入

- 提供 OpenAI 兼容的模型调用入口，支持流式与非流式调用。
- 可连接多个模型供应商、兼容渠道和企业内部模型服务。
- 应用使用统一凭证和入口，管理员可在网关侧调整模型与渠道配置。
- 模型列表只展示调用者当前有权访问且具备可用路由的模型。

网关兼容不代表支持某个上游协议的所有参数。请求能力取决于模型、上游渠道、端点格式和管理员发布配置。

## 路由与连续性

- 根据组织和产品范围、渠道状态、容量、成本、优先级与权重选择候选渠道。
- 支持为模型配置备用渠道和受控恢复策略。
- 对可安全恢复、且尚未向客户端提交业务输出的失败，可在预算范围内进行透明恢复。
- 保留请求模型身份、实际路由和恢复过程所需的审计信息。

恢复并不保证每个失败请求都成功。已经产生业务输出、语义不安全或超出恢复预算的请求会返回原始错误。

## 权限与 API Key

- 按组织、产品、成员和 API Key 隔离访问范围。
- 可限制 API Key 可访问的模型，并配置 RPM、TPM 和额度边界。
- API Key 明文只在受控创建或轮换流程中交付；平台不应在后续页面完整回显。
- 支持管理员撤销凭证和追踪凭证使用情况。

API Key 属于敏感凭证，只应由服务端保存和使用。不要在浏览器、移动端、日志或公开反馈中暴露。

## 用量、成本与预算

- 记录输入、输出及其他可计量资源的使用情况。
- 按组织、团队、成员、应用、凭证、模型和时间分析消费。
- 支持组织和成员维度的额度、限额与用量约束。
- 将客户计费、渠道成本和异常结算状态分别记录，便于核算与对账。

最终计费取决于发布价格、模型计量方式和上游返回的用量证据。上游未提供可靠用量时，平台会按已配置规则处理，不应将未知成本误报为零。

## 服务质量与审计

- 展示请求成功率、延迟、错误类型和模型或渠道对比。
- 提供请求与消费日志，支持按权限进行筛选和追溯。
- 支持渠道健康检查和运行异常分析。
- 对管理配置、凭证和关键计费操作保留必要审计信息。

日志和观测数据按权限提供。出于安全和隐私考虑，平台不会在公开社区协助检索包含敏感数据的具体请求。

## 能力状态

我们在版本说明中使用以下状态：

| 状态 | 含义 |
| --- | --- |
| 正式可用 | 已进入稳定支持范围，变更遵循兼容性政策 |
| 预览 | 可供验证，接口或行为可能在发布说明后调整 |
| 受限开放 | 仅对指定租户或场景开放，需要联系支持团队 |
| 已弃用 | 仍可使用但计划移除，会提供迁移说明和时间窗口 |

没有明确标记为“正式可用”的路线图条目，不应视为产品承诺。
